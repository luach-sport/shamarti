# שמרתי

אפליקציית אנדרואיד ששומרת סרטונים מטיקטוק, אינסטגרם, יוטיוב ופייסבוק, אתרים וכל קישור, עם תיאור שאתה כותב, קטגוריות ותמונה של הסרטון. ככה גם בעוד 30 שנה תמצא את מה ששמרת.

## הורדה

**[הורדת האפליקציה (shamarti.apk)](https://github.com/luach-sport/shamarti/releases/latest/download/shamarti.apk)**

הקישור תמיד מוביל לגרסה האחרונה.

### התקנה בטלפון
1. פותחים את הקישור בטלפון ומורידים את הקובץ.
2. פותחים את הקובץ שירד. בפעם הראשונה הטלפון יבקש לאשר "התקנה ממקור לא ידוע". מאשרים.
3. מתקינים ופותחים.

**עדכון:** העדכונים נכנסים מתוך האפליקציה (הגדרות ← בדיקת עדכונים). השמירות נשארות.

## איך שומרים
- **שיתוף:** בטיקטוק, באינסטגרם, ביוטיוב או בכל דפדפן לוחצים "שיתוף" ובוחרים **שמרתי**. מסך השמירה נפתח עם הקישור.
- **העתק-הדבק:** מעתיקים קישור ונכנסים לאפליקציה. היא מזהה את הקישור ומציעה לשמור. אפשר גם ללחוץ "שמירה" ו"הדבקה".

## מה יש באפליקציה
- **תמונה וכותרת לבד:** ברגע שמדביקים קישור, האפליקציה מושכת את תמונת הסרטון, הכותרת והיוצר (כמו התצוגה של וואטסאפ), ושומרת אותם בטלפון. גם אם הסרטון יימחק מהרשת, התמונה והתיאור נשארים. שמירה שנשארה בלי תמונה תקבל אותה לבד כשיש אינטרנט, ואפשר גם לצרף צילום מסך משלך.
- **הורדת סרטוני טיקטוק:** בדף של השמירה לוחצים "הורדת הסרטון לטלפון". אחרי ההורדה אפשר לצפות בלי אינטרנט, לשתף את הסרטון כקובץ ולשמור בגלריה. אם היוצר חסם הורדות בטיקטוק, או שהסרטון פרטי או נמחק, האפליקציה אומרת את זה ולא מורידה.
- **שיתוף:** כקישור, או כקובץ של הסרטון אחרי שהורד.
- **התיאור שלי, קטגוריות ותגיות:** כותבים מה זה ולמה שמרת, בוחרים קטגוריה (אפשר להוסיף כמה שרוצים) ומוסיפים תגיות.
- **חיפוש וסינון:** חיפוש בכל מה שכתבת, בכותרת, בתגיות ובקישור. סינון לפי מקור (טיקטוק, אינסטגרם, יוטיוב, אתרים, ומקורות שהוספת), לפי קטגוריה ולפי תאריך.
- **מועדפים**, העברה בין קטגוריות, ופתיחה ישר באפליקציה המקורית.
- **גיבוי ושחזור** (כולל התמונות), ייצוא לאקסל, ותזכורת לגבות פעם בשבוע.
- **מצב בהיר / כהה / לפי הטלפון**, ופנייה / הצעת ייעול שמגיעה במייל.

## איך זה בנוי
הקוד מחולק להרבה קבצים קטנים, קובץ לכל יכולת, כדי שיהיה קל לתקן ולשנות. הפירוט המלא ב-`CLAUDE.md`.
- `www/js/`: האפליקציה (JavaScript בלי תלויות), בתיקיות: `core` (בסיס), `links` (קישורים ותמונות), `video` (הורדות), `data` (נתונים וגיבוי), `ui`, `views` (מסכים), `sheets` (חלונות), `features` (רקע), `actions` (כפתורים), `app` (הפעלה). `www/css/`: העיצוב.
- `scripts/patch-android.sh`: התאמות לאנדרואיד, כולל הופעה בתפריט "שיתוף".
- `android-res/`, `tools/`: האייקון ומסך הפתיחה, והכלי שמייצר אותם.
- `tests/`: בדיקות אוטומטיות בדפדפן לכל המסכים, לתמונות ולהורדות.
- `.github/workflows/build.yml`: כל דחיפה ל-main בונה APK חתום, מפרסמת אותו ב-Releases ומכינה עדכון שנכנס מתוך האפליקציה.
- `feedback/`: הסקריפט ששולח את הפניות מהאפליקציות למייל של המפתח (משותף ל-MyCar ולשמרתי), מחולק לקבצים קטנים כמו בפרויקט "שליחת פניות Mycar" ב-Google Apps Script.
- `signing/release.jks`: מפתח החתימה, מוצפן. הסיסמה שמורה בסוד `SHAMARTI_KEY_PASS` של הריפו.
